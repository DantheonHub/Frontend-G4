## Convención de commits

Cada commit representa una clase o un avance importante dentro del bootcamp.

Formato:

```text
tipo(área): [Módulo | Clase] descripción
```

Cuando una clase contiene un curso interno, se agrega el módulo correspondiente:

```text
feat(css): [Módulo 2 | Clase 3 | Curso CSS - Módulo 2] Fundamentos de CSS
```

Ejemplos:

```text
feat(html): [Módulo 2 | Clase 1] Fundamentos de HTML
feat(css): [Módulo 2 | Clase 2] Fundamentos de CSS
feat(css): [Módulo 2 | Clase 3 | Curso CSS - Módulo 2] Fundamentos de CSS
```
